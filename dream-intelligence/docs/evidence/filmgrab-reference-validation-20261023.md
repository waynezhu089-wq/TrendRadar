# 视频创作灵感参考：FilmGrab 第一批接入

## 已交付范围

图片方案现可选择 FilmGrab、Openverse 或两者。设置中的手动方案和方案助手均使用服务端已接入来源约束；既有方案保留原来源，页面可展开“调整参考来源”修改。保存只改变来源，不采集、不调用模型，保留目的和历史。没有新增数据库列、定时任务或通知。

FilmGrab 按片名、导演、摄影师检索，跟随真实搜索结果的同站电影页，每词最多2片，每片抽取首、中、末3帧预览。每来源最多2个检索词，单次总候选最多12张；双源各留6个位置。拒绝、超时或限流停止该源请求，成功来源继续保留。图片身份去掉缓存查询参数后生成稳定哈希，按 provider + external_id 去重，重新采集可补全主创和原站使用说明，保留收藏。

接受带水印的公开预览，不移除水印。FilmGrab 来源不伪装为开放许可图片，保留影片、主创、原链接及原站明确的使用说明，不提供平台内原图下载。用途判断仍仅使用元数据；未实现像素识别或视频节奏分析。
