# YouTube 视频灵感：配置与使用

第一版保存视频链接、公开封面、中文标题/简介和分类，支持原站或嵌入预览与收藏。不下载视频文件，不读取账号 Cookie，不观看完整视频；中文整理依据是公开标题与简介。

## 申请接口密钥

1. 打开 [Google Cloud 控制台](https://console.cloud.google.com/)，登录并创建一个供 DSIH 使用的项目。
2. 在“API 和服务 → 库”搜索 **YouTube Data API v3**，确认项目正确后启用它。
3. 在“API 和服务 → 凭据”选择“创建凭据 → API 密钥”。
4. 编辑该密钥，将“API 限制”设为仅允许 **YouTube Data API v3**。这是本机后端访问，不要配置成仅允许网页 HTTP 引荐来源。若设置 IP 限制，需要使用实际对外出口 IP。
5. 不要把密钥发送到聊天、写入前端或提交 Git。Qwen / DeepSeek 密钥不能代替 Google 密钥。
6. Windows 搜索“编辑账户的环境变量”，在“用户变量”中新增：名称 `DSIH_YOUTUBE_API_KEY`，值为刚生成的密钥，保存。
7. 新进程才能继承新变量。完全退出并重新启动当前开发环境后告知 Codex；Codex 会先检查是否可读取，不显示密钥，再做一次小规模真实采集验收。若用 Windows 计划任务启动 Scheduler，也需要该任务的进程重新启动后才能继承变量。

官方参考：[开始使用](https://developers.google.com/youtube/data/getting-started)、[搜索接口](https://developers.google.com/youtube/data/reference/rest/v3/search/list)。接口配额以 Google Cloud 控制台实际显示为准，不保证无限搜索。遇到权限/配额错误时，本次采集停止继续搜索其他话题。

## 使用

- 设置 → 议题与来源 → 手动填写关注方案 → 收集类型 **YouTube 视频灵感**。也可让方案助手拟草案，确认后创建。
- 可输入最多八个关键词；快捷方向为动物趣事、动物互助与救援、人类搞笑、温暖互助。英文搜索词便于寻找海外内容，分类与简介会整理成中文。
- 每话题每次最多十条近三十天候选，最多八次搜索，不分页追加请求。交替使用相关度和时间排序，多话题轮流取样，选入最多十二条、同频道每次最多两条，以视频 ID 去重。英文短语后附中文说明时，执行检索会分离中文说明，原方案话题保留。不同方案可分别填写用途。再次收到同一视频时复用已保存的中文整理；未完成的中文整理在再次收到该视频时重试。
- “本次检索”可查看实际检索词、排序和候选/入选的频道数。历史未保存的检索过程不会补造。频道分散不代表视频一定来自不同原始素材，不能据此排除搬运、摆拍或 AI 生成；当前仍只按标题与简介整理。
- Research 中点击 **现在运行** 手动收集。新方案默认不自动收集、不发送飞书。
- 在方案内 **定时收集设置** 选择每 2 / 6 / 12 小时或每天一次。保存设置不会立即采集，首次计划从保存后所选间隔计算。关闭可停止后续自动采集，已经运行的一次会保留其结果。
- 运行中的新版 Scheduler 每五分钟检查到期方案；每轮最多三个方案，繁忙时可能继续顺延。电脑需开机、网络可用。网页会区分“已保存设置”和“定时服务已连接且已读取密钥”。旧 Scheduler 未加载新功能时不会声称自动采集已生效。
- 视频区跨次保留条目，最多展示最近 100 条，按原发布时间倒序。每个分类先显示两条，按需展开；收藏按方案隔离且跨次保留。预览由 YouTube 播放器提供，禁止嵌入的视频可打开原站。
- 分类不等于事实核实或素材授权；例如“动物互助”只表示标题/简介提供的题材线索。没有完成中文整理的条目显示原文和待整理状态。
