## 安装与启动（Windows）

建议 Python 3.12+、Node.js 22.12+、Git；按仓库 `backend/pyproject.toml` 和 `frontend/package-lock.json` 安装。

终端一，位于 `dream-intelligence`：

```powershell
python -m venv backend\.venv
& .\backend\.venv\Scripts\python.exe -m pip install -e './backend[test]'
cd backend
& .\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

终端二，位于 `dream-intelligence`：

```powershell
cd frontend
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173/`；健康接口 `http://127.0.0.1:8000/api/v1/health`。应用启动创建空表，不自动生成 Mock；如开发测试需要，在 backend 中显式运行 `python -m app.db.seed`。

## 环境配置与可选依赖

`.env.example` 是空值模板，应用不自动加载 `.env`。请在新主机本地配置进程/Windows 用户环境变量并让后端进程重新读取；不要将真实值提交。

| 功能 | 新主机配置 |
|---|---|
| 文本模型 | `DSIH_LLM_BASE_URL`、`DSIH_LLM_MODEL`、`DSIH_LLM_API_KEY`；只在本机设置 |
| YouTube | `DSIH_YOUTUBE_API_KEY`；参见 `docs/YOUTUBE_SETUP.md` |
| 图片视觉 | `DSIH_VISION_BASE_URL`、`DSIH_VISION_MODEL`、`DSIH_VISION_API_KEY_ENV` 指向本机密钥变量；旧机复用的 `VNEXT_QWEN_API_KEY` 不会随仓库迁移 |
| 飞书 | `DSIH_FEISHU_WEBHOOK_URL`、`DSIH_FEISHU_BRIEF_TIME`、`DSIH_FEISHU_BRIEF_TIMEZONE`；原定时偏好为 08:30 / Asia/Shanghai，配置本身不代表已验收发送 |
| NewsNow | `NEWSNOW_API_URL` 可选，支持公共或自建接口 |
| B站 | 单独安装 MediaCrawler，设置 `DSIH_MEDIACRAWLER_DIR`，其目录需要自己的 `.venv\Scripts\python.exe`；参考 README 中的 MediaCrawler 章节。第三方源码不混入 DSIH |
| 浏览器来源 | 安装 Chrome / Edge，必要时在 backend 环境执行 `python -m playwright install chromium`；在本机专用窗口亲自登录，不迁移 Cookies/浏览器 profile |

B 站外部工具原机位于工作区 `.lab-tools/MediaCrawler-main`；默认相对路径适用于其位于 `dream-intelligence` 的同级 `.lab-tools/` 目录的布局，也可用上述变量显式指定。仓库不包含第三方下载包、外部虚拟环境和登录配置，需根据 README 独立安装并核查其许可/接口兼容性。

本机对 MediaCrawler 两个文件的少量改动也已保存为 [外部工具差异补丁](external/README.md)，同时附原包 SHA256 和原许可，避免遗漏本机开发差异；不要将旧浏览器会话一起迁移。

## 数据、登录和定时任务的迁移边界

这是公开源码归档，不是原机运行状态备份。`data/`、数据库/备份、浏览器 profile、下载素材、模型凭据、日志、缓存和依赖目录均不上传。因此，新机的方案、收藏、历史条目和通知防重记录初始为空。工单与验收文件中的历史计数是原机当时的证据，不应称为新机已验收。

若之后要迁移原机数据库，应另行通过用户认可的私密渠道做一致性备份；不要放到此公开仓库。不要删除或重新 Seed 原机数据库。浏览器需新机亲自登录，不复制原机认证会话。

**接力开发初期只启动 API 和前端。不要在第二台主机同时启用飞书发送 Scheduler。** 两台主机使用独立数据库时，通知防重不共享，可能重复发送。需要另行确定唯一运行通知的主机后，再阅读 `scripts/install_scheduler_task.ps1` / `install_scheduler_watchdog_task.ps1` 和相关工单；仓库内存在安装脚本不代表新机已注册任务。
